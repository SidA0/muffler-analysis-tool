05

Prepare an Ansys acoustic input

Export a selected RPM spectrum as pressure amplitudes for a Harmonic Acoustics model.

The APDL file defines a frequency-dependent prescribed acoustic pressure on the named nodal component. Create and scope that component in your Ansys model, then insert the commands in the Harmonic Acoustics analysis. FFT SPL provides magnitude only, so the export assumes zero phase at every frequency. It cannot recover the physical source phase or geometry, and prescribed pressure does not include reflections at the excitation boundary. Validate the result in your model before using it to predict attenuation.

Method: Each frequency bin is C weighted (unless the source is already dBC), converted to linear sound energy, then summed per RPM: 10 log₁₀(Σ10^(Lᶜ/10)). Repeated measurements at the same RPM and frequency are energy averaged first. The attenuation curve subtracts dB at each frequency, with linear interpolation between entered points, before the bins are summed again. Contribution shows association with the measured total, not proof of physical causation. Results depend on the FFT export's calibration and bin coverage.

OPT

Find the frequency cuts

Choose an RPM and a goal. The solver searches for band reductions that reach it with limited overall effort.

HOW IT SEARCHES

Reduce the loudest energy first, then smooth the curve.

The iterative solver minimizes the squared dB cuts across frequency bands while penalizing abrupt changes between neighboring bands. It enforces the target after the pressure margin. Recommended cuts are capped at 60 dB per band.

The margin is a percentage of linear sound pressure: a 10% margin targets about 0.92 dB below your entered dBC value. Run times vary by device and can finish early when the solver converges.
